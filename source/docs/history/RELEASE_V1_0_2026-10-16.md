## 실제 수행한 검증

**패키지/적용**: 스테이징과 ZIP 압축 해제 결과를 대조했다. 압축 해제 경로에 한글과 공백을 포함해 Windows PowerShell·Python·CMD 적용을 실제 실행했다. 결과가 008과 일치하며, 잘못된 원본·다른 내용의 기존 출력·원본을 출력 경로로 지정하는 요청은 거부했다. 원본은 보존했다. 동일 입력으로 패키지를 다시 만들어 ZIP 해시가 같음을 확인했다.

**실제 공개 릴리즈**: 공개 ZIP을 GitHub에서 다시 다운로드해 로컬 ZIP과 바이트 대조했다. 재다운로드한 ZIP의 적용 도구도 같은 검사를 통과했다. 공개 Git 저장소를 새로 복제해 체크섬 목록의 21개 파일을 검증하고 Python/PowerShell 적용을 검사했다. Git 체크아웃의 줄바꿈이 검증을 바꾸지 않도록 배포 저장소에 `.gitattributes`를 두었다.

**사이트/배포**: 기존 20개 게임의 원장 내용을 보존하고 새 항목만 추가했다. 원본 256×240 타이틀 PNG를 가공 없이 연결했다. 사이트 정적·DOM 검사 통과 후 main에 푸시했고 Actions의 build와 deploy 성공을 확인했다. 공개 `catalog.json`/`catalog.js` 일치와 이미지 해시도 확인했다.

**브라우저**: 격리된 Microsoft Edge로 로컬 및 실제 공개 주소를 1440×1000, 390×844에서 각각 검사했다. `Tom & Jerry` 검색, v1.0/배포 중 표시, 소개창, PNG 로드, 실제 릴리즈 링크와 미검증 안내를 확인했다. 가로 넘침과 JS 오류는 없다. 공개 페이지 캡처도 직접 열어 확인했다. 사이트의 방명록/버그 신고는 새 저장소의 라벨·양식과 연결했다. 글이나 신고는 대신 게시하지 않았다.

**게임 실행 근거**: 이번 세션에서 새 에뮬레이터 실행이나 플레이를 하지 않았다. 배포 결과가 기존 008과 같으므로 그 정상 도입 3페이지·첫 스테이지 진입과 진단 엔딩 1페이지 증거를 동일 바이트에 한해 연결한다. [본문 삽입 008 보고서](TEXT_INSERTION_008_2026-10-16.md)의 근거 범위를 그대로 유지한다.

## 알려진 범위와 미실시 사항

타이틀 두 부분과 도입부·엔딩 일본어 18행을 한글화했다. `PUSH START BUTTON`, 영문 저작권·스테이지 안내·점수 등 일부 영어는 그대로다. 글자 수 차이로 도입 글자 출력/페이지 전환 시점 일부가 달라진다.
