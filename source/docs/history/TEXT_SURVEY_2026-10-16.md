## 텍스트 소비 경로

- PRG에서 `JSR $F178` 바이트 패턴 15곳을 찾고 이어지는 인라인 스크립트를 파싱했다. 15곳 모두 알려진 제어코드와 종료자를 가진 구조로 해석됐다.
- `$F178`은 스택의 호출 복귀 주소를 꺼내 그 다음 바이트를 스크립트로 읽는다. 따라서 인라인 텍스트의 크기가 바뀌면 뒤 코드 위치와 분기·참조까지 고려해야 한다. 일반 포인터 문자열처럼 임의로 길이를 늘리면 안 된다.
- `$F18B`는 스크립트 바이트를 읽고 양수 바이트를 문자로, 상위 비트가 설정된 바이트를 제어코드로 나눈다. 문자 출력은 `$F1B7..$F255`, PPU `$2007` 쓰기는 `$F1D4`다.
- `$80`은 종료 후 뒤 코드로 복귀, `$81 x y`는 위치 지정, `$82 y`는 가로 중앙 정렬, `$83/$84`는 표시 비활성/활성 루틴, `$85`는 속성 선택 인자 1바이트, `$86`은 팔레트 인자 4바이트다. 인라인 코드와 디스패치 테이블은 명령어로 해독하지 않고 분리했다.
- 공식 명령의 디스어셈블은 설치된 `py65==1.2.0`을 사용했다. 직접 만든 부분 6502 디코더나 코드 생성·수정은 사용하지 않았다. 증거는 `text_engine_disassembly.txt`다.

## 문자와 폰트

일본어는 Shift-JIS가 아니라 게임 고유의 7비트 타일 번호다. 문자 값이 네임테이블에 그대로 기록된다. 일본어 폰트는 파일 `0x2A810..0x2B00F`의 2KiB 영역이며, 도입 화면에서 PPU 패턴 `$0000..$07FF`와 바이트 단위로 같다.

탁점·반탁점은 별도 타일이다. 예를 들어 화면의 `ず`는 `す`와 탁점 코드로 저장된다. 긴소리 기호처럼 같은 글자를 표시하는 번호가 여럿 있어, 정규화된 원문 텍스트만으로는 무손실 재삽입할 수 없다. 카탈로그의 `glyph_units`, 원시 hex와 제어 토큰을 보존한다. 사용하지 않은 `$3B/$3C` 글리프는 뜻을 확정하지 않고 이름 없는 값으로 남겼다.

카탈로그의 `tile_width`는 탁점·공백을 포함한 원본 셀 수다. 한국어 번역의 글자 수 제한이나 추가 공간 예산이 확정됐다는 뜻은 아니다.

## 조사 분모와 제외

CHR 128KiB 전체를 4KiB×32뱅크 미리보기로 만들어 시각 조사했다. 일본어 폰트 그룹 하나를 식별했다. 이것은 CHR 정적 시각 조사이며 전체 게임 실행 검증을 대신하지 않는다.

나머지 인라인 스크립트 11곳은 영문 폰트의 크레딧·PUSH START BUTTON·PRESS START TO CONTINUE·CHEESE BONUS·EXTRA LIFE·HUD·GOOD JOB·GAME OVER·COLLECT THE CHEESE·WORLD/STAGE 안내다. 문자 값이 일본어 폰트에도 존재한다는 이유만으로 일본어 후보에 섞지 않았다. 영문 판독은 `inline_scripts.json`의 `english_font_reading`에 분리했다. `$04`처럼 숫자 0/O를 공유하는 값과 일부 영문 기호는 원시 표기를 유지했다.

조사 분모는 **이 리비전 PRG의 `$F178` 직접 호출 패턴 15곳과 CHR 정적 미리보기**다. 간접 호출·다른 출력 엔진·전체 실행 경로의 완전성은 입증하지 않았다. 일본어 전체가 반드시 이 18행뿐이라고 확정하지 않는다.

## 검증 종류

### 정적 추출

명령: `python .\scripts\record_text_engine.py`, `python .\scripts\extract_japanese.py`.

15개 스크립트의 토큰→원시 바이트 왕복이 동일했다. 원본 해시와 최신 한글 타이틀 ROM 해시가 기존 값과 같음을 확인했다. 새 ROM이나 IPS는 만들지 않았다.

### 실행 확인

Mesen 2.2.1, 기존 타이틀 QA와 같은 실행 파일 해시·격리 설정으로 원본을 정상 부팅해 1500/1800/2100/2400/2700/3000/3300프레임을 수집했다. 1800/2100/2700프레임의 도입부 3페이지를 직접 열어 확인했고, 12행 전부 원문 바이트→PPU 위치·값 및 폰트가 일치했다.

증거: `qa/text_survey_001/intro_pages/`, `qa/text_survey_001/extraction_verification.json`.

`japanese_text_survey.png`의 도입부 3장은 실제 실행 캡처다. 우측 하단 엔딩은 원본 폰트와 스크립트로 재구성한 **정적 텍스트 미리보기**이며 게임 캡처가 아니다. 이미지에도 이 구분을 표시했다. 엔딩에 강제로 진입하거나 일반 플레이로 도달하지 않았다.

### 미실시

한글 번역·폰트 설계·재삽입·새 패치 빌드·엔딩 정상 도달·전체 플레이는 하지 않았다. 타이틀 빌드를 재검증했다는 주장 대신 그 ROM과 IPS의 기존 해시가 유지됨을 확인했다.
